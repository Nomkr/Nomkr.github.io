## 智能推拿手套：小鱼际㨰法局部三维轨迹重建

### 背景与问题

㨰法是中医推拿的代表性手法，但传统教学依赖"师傅手把手"的经验传授，动作是否标准——前滚角度、力度、频率、接触点是否"吸定"——缺乏客观、量化的评价手段，难以用数据衡量。

*智能推拿手套实物*

### 方法

- **可穿戴传感**：双 MPU6050 惯性传感器（手背 + 手腕）+ 48 通道薄膜压力阵列，STM32 主控，蓝牙传输。
- **上位机**：基于 Unity 的采集上位机，负责串口通信与二进制数据解析、压力热力图/姿态实时显示、多路数据同步落盘；配套 Python 脚本完成传感器标定、双目视觉真值与时间同步。
- **视觉真值**：双目相机 + ArUco 标记，经标定与三角化获得手部三维位置与姿态真值（基线 64.79 mm，静态精度 0.19 mm）。
- **深度学习**：以 IMU + 压力信号为输入，重建手部三维轨迹；训练用视觉真值，部署只需可穿戴传感器，不依赖相机与动作捕捉系统。

### 创新点

1. 把中医手法"做得规不规范"量化为可测指标——前滚角 / 回滚角 / 力度比 / 频率 / 接触点滑移量；
2. 微小区域的轨迹重现；
3. 穿戴式方案适配真实教学与临床场景，成本远低于光学动作捕捉；
4. 双 IMU 设计有明确生物力学依据（前臂 / 腕部）。

### 当前进展

已完成传感器标定、双目标定、精度验证（静态 ≤0.2 mm、位移 ≤1 mm）、相机-IMU 时间同步（<10 ms），正在推进可行性数据采集与网络训练。
